# AyosDito Phase 1 Implementation Plan

> For agentic workers: use superpowers:executing-plans for inline execution.

**Goal:** Deliver the approved Phase 1 brief: bilingual authentication and protected resident/admin dashboards backed by Supabase.

**Architecture:** Next.js App Router with request-scoped Supabase SSR clients. Server authorization reads the database role; RLS restricts all five application tables. No privileged Supabase key in the application.

**Tech Stack:** Current stable Next.js, React, TypeScript, Tailwind, Supabase SSR and PostgreSQL.

**Spec:** User-provided PROJECT BRIEF: AYOSDITO, accepted as final on 2026-11-22.

## Global Constraints

- Start with Phase 1 only. Do not implement the entire application immediately.
- Never hardcode credentials, secret keys, or passwords.
- Enforce authorization on the server and through PostgreSQL RLS.
- Do not proceed to Phase 2 until Phase 1 is tested and approved.

## Review Focus

- Missing environment configuration must show an actionable setup screen without crashing.
- Tampered role metadata must never grant administrator privileges.
- Direct admin URLs and actions must reject residents.
- Expired sessions, invalid credentials and missing profiles must fail closed.
- Filipino must cover login validation, dashboard labels and errors.
